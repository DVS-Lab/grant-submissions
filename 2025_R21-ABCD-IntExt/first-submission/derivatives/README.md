# Derivatives Directory

This directory contains all processed data, analysis results, figures, and output files generated from the source data and analysis scripts for the ABCD Study project examining environmental and neural drivers of internalizing and externalizing behaviors in adolescents.

## Content Overview

### `figures/`
Contains all publication-ready figures and visualizations generated from analysis scripts.

**Main Figures:**
- `R21-ABCD_figure-2_behavior-adiXinternXcohesion.pdf`: Bar plot showing internalizing symptoms by ADI level and social support groups
- `R21-ABCD_figure-3_aa_adiXinternalizingXcohesion.pdf`: Faceted visualization of brain imaging measures across multiple grouping variables
