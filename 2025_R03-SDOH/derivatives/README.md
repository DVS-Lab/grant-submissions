# Public derivatives

Only aggregate results and figures reviewed for absence of participant
identifiers belong in this public directory. Participant-level scoring tables
and analytic masters are generated in private storage and are ignored by Git.

`model-screening/` contains three reviewed coefficient/formula-level references
from the prior exploratory screen. They contain no participant rows and are
used by the private pipeline to reconstruct the historical formula set.

No participant-level SDOH CSV is currently approved for public release.
